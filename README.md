# Aurora Shelf — Orion vF2.1.1

Primeiro protótipo completo do Universo Orion.  
Gerenciador de PDFs com leitura e anotações humanizadas.

## Setup

1. Instale dependências em cada módulo (`client`, `server`, `data`).
2. Execute `npm run dev` (client) e `npm start` (server).
3. Consulte `/doc/internal` para documentação Orion.
